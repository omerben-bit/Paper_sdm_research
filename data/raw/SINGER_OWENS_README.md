# Singer & Owens depth-curated fish occurrences (iDigBio)

**Citation:** Singer, R.A. & Owens, H.L. Global, depth-resolved marine fish occurrences from digitized natural history collections. *Scientific Data* (2026).  
**Dataset (latest):** [Zenodo 10.5281/zenodo.22124920](https://doi.org/10.5281/zenodo.22124920)

Place the file here:

`data/raw/iDigBioProcessedFishOccurrences_SingerAndOwens.csv`

(~119 MB, curated specimen records with **mean depth in meters**).  
This is **not** a GBIF download; it is the authors’ cleaned iDigBio pipeline (354k+ global records).  
In the Israel/Levant map box, counts are **small** (museum vouchers) but every record has depth.

Older Zenodo file name also supported: `processedFishDataWithDatesAndNames.csv`.
